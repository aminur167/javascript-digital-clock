# Digital Clock

Real-time digital clock web application displaying current time and date with smooth styling.

## Features

- Live hours, minutes, and seconds display
- Current date and day of the week
- Clean dark-themed UI
- Smooth CSS transitions
- Responsive design

## Files

```
index.html   - HTML structure
style.css    - Dark theme styling
script.js    - Clock logic with setInterval
```

## How It Works

Uses `setInterval()` to update the display every second with `new Date()` methods for accurate time.
